# B.K.D.M

Página pessoal com animação de corações criada em HTML, CSS e JavaScript.

## O que você encontra

- A estrutura da página está no HTML e os estilos ficam na pasta CSS.
- O script cria os elementos animados na página.

## Executar localmente

Baixe ou clone o repositório e sirva a pasta raiz com um servidor estático. Com Python 3 instalado, execute `python -m http.server 8000` e acesse [localhost:8000](http://localhost:8000/).

## Arquivos principais

- [`index.html`](index.html)
- [`css/extends.css`](css/extends.css)
- [`js/js.js`](js/js.js)
